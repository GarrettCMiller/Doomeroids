# Doomeroids

Doomeroids began as a one-month Full Sail project by Garrett Miller and
continued as a personal game-development experiment. Built in C++ for Windows,
it uses Garrett's [GLib](https://github.com/GarrettCMiller/GLib) framework and
DirectX-era graphics and game services.

The source explores interacting gameplay systems, including player and enemy
entities, weapons and projectiles, collision handling, scripted events and
data-driven game definitions. The repository also contains experiments in
game-development tools.

## Repository guide

- `Doomeroids/`: game source, project files, scripts and resources.
- `Map Editor/`: an MFC tile-map editor experiment. Its saved map-writing path
  is unfinished in the reviewed source.
- `DPak/`: a front end for packaging and inspecting game resources.
- `Game/` and `SS/`: historical packaged game and solar-system experiments.

## Status and dependencies

This is an archival work-in-progress and portfolio code sample. It has not
been rebuilt or run for this README. The source references Windows, MFC,
DirectX-era components and a compatible version of GLib; exact dependency
versions and build settings still need to be established. Included binaries
have not been verified against the source.
